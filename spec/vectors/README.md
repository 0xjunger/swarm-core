# Test vectors

This is the corpus `SPEC.md` §8 describes. It makes the specification
falsifiable: a second, independent implementation of `V` is checked against
these files, not only against the prose in `SPEC.md`.

## Format

Each vector is a named scenario with three files:

- `<name>.bundle` — a canonically encoded `LogBundle` (`SPEC.md` §4.4, §5).
- `<name>.spec` — a canonically encoded `Spec` (`SPEC.md` §4.5, §5).
- `<name>.expected.txt` — the expected result of `V(bundle, spec)`: the
  status of each invariant (`Satisfied`, `Violated` with its `Witness`
  kind, or `Undetermined` with its reason), any chain-level finding, and
  the reference CLI's exit code.

## Layout

- `positive/` holds bundles for which every invariant `V` can check is
  `Satisfied` and no chain finding is present.
- `negative/` holds one scenario per way `V`'s checks (`SPEC.md` §6–§7) can
  find a problem: an equivocation, an overspend, a chain that fails
  verification, a chain filed under the wrong author, a bundle too sparse
  to determine agreement between observers, and a bundle that fails to
  decode before `V` ever runs.

## Provenance

These files are copies of this project's own canonical fixture corpus at
`crates/swarm-verify/tests/fixtures/`, which is generated by one shared
function (`crates/swarm-verify/tests/support/fixture_data.rs`) and checked
by a test that the committed bytes match a fresh regeneration
(`crates/swarm-verify/tests/fixtures.rs`). If that corpus changes, copy the
updated files here too — this directory does not regenerate itself
automatically.

## Adding a vector

Construct the scenario's bundle and spec using the canonical encoders
`SPEC.md` §5 defines, place both files in `positive/` or `negative/` as
appropriate, and write the matching `<name>.expected.txt` by actually
running a conformant implementation of `V` against the two files — do not
hand-write the expected result from the specification text alone; every
`.expected.txt` file in this corpus was produced by running the reference
implementation, not derived by hand from the prose.
